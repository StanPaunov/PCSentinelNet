What it monitors

System, network, firewall, and security details

Performance

  • CPU, memory, system disk usage, and aggregate network throughput.
  • Top processes by CPU time, with double-click or right-click internet search.
  • Alerts for high resource usage.

Network

  • Active network interfaces with upload and download rates.
  • Listening TCP ports in the Network & Firewall tab, with double-click or right-click internet search.
  • TCP connections, with double-click or right-click internet search.
  • Alerts for sensitive listening ports and outbound connection attempts.

Firewall and Security

  • Firewall profile information in the Security tab.
  • Windows Firewall profile status.
  • Microsoft Defender real-time protection and signature timestamp when available.
  • Alerts for disabled firewall profiles.

Disk and Windows Info

  • Disk and volume inventory with links to Windows Disk Management and Storage Settings.
  • Basic hardware, operating system, BIOS, hotfix, and installed software information where Windows allows access.

Install

Run the desktop app

  1. Download the latest zip from GitHub Releases.
  2. Extract the zip to a normal folder such as Downloads or Documents.
  3. Run PCSentinelNet.exe.
  4. For Android, open the Sentinel Mobile project in this repository or download APK releases when published.

Security model

Local visibility first

PC Sentinel NET reads Windows system information locally. It is not a packet sniffer and does not upload monitoring data.

Listening TCP ports are summarized so you can judge exposure: localhost-only ports are usually lower risk, while public listening ports deserve closer review.

PC Sentinel Mobile is included as the Android companion for Windows PC monitoring. Android-phone monitoring should live in a separate app. Unsigned Windows apps can show SmartScreen warnings until code signed.
